# Architecture Rules

## Purpose
Define the project architecture, dependency direction, module boundaries, and reuse principles.

## Core Rules
- Inspect the existing codebase before changing architecture.
- Keep responsibilities explicit and dependencies directional.
- Prefer composition and simple boundaries over premature abstraction.
- Do not restructure unrelated areas during a small task.
- Preserve current behavior unless a feature change is explicitly requested.
