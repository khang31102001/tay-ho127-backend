# TASK — Build Customer Module + Media

## Context

Hãy xây dựng module `Media` dựa trên database design sau:

```dbml
Table media {
  id varchar [pk]
  file_name varchar [not null]
  url varchar [not null]
  kind media_kind [not null, note: 'FE field name is "type"']
  alt_text varchar
  size int [not null, note: 'bytes']
  status entity_status [not null, default: 'active']

  Note: 'Shared media library referenced by Product, Customer, Article, Banner, BrandSettings, PaymentMethod, PageSection'
}
